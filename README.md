# Movie Explorer App
A cross-platform mobile application built using .NET MAUI that allows users to browse, search and manage their favourite movies.

---
### Some of the features:
- Search movies by title, genre, director, year or rating
- View detailed movie information with cover images
- Add and manage favourite movies
- Local caching for offline access
- Customisable UI (theme colors, text size)
- Genre-based background music in movie details
- Navigation using Shell routing
  
---
### Technologies used:
- .NET MAUI -> Cross-platform mobile development
- C# -> programming language
- Model–View–ViewModel -> separates User Interface from logic
- JSON -> API communication 
- HttpClient -> used to fetch movie data
- ObservableCollection -> updates user interface dynamically
- Plugin.Maui.Audio -> audio playback

---
#### Setup instructions
1. Open the file MovieExplorer.sln in Microsoft Visual Studio
2. Select **Windows Machine** at the top
3. Run the application
