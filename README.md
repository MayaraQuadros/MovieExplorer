    Movie Explorer App
    A cross-platarfom mobile application built using .NET MAUI that allows users to browse, search and manage their favourite movies.

    Some of the features:
    -Search movies by title, genre, director, year or rating
    -View detailed movie information with cover images
    -Add and manage favourite movies
    -Local cashing for offline access
    -Customisable UI (theme colors, text size)
    -Genre-based background music in movie details
    -navigation using Shell routing

    Technologies used:
    -.NET MAUI -> Cross-platform mobile development
    - C# -> programming language
    - Model–View–ViewModel -> separates User Interface from logic
    - JSON -> API communication 
    - HttpCLient -> used to fecth movie data
    - ObservableCollection -> updates User Interface dinamically
    - Plugin.Maui.Audio -> audio playback

    Setup instructions
    Open the file MovieExplorer.sln in Microsof Visual Studio
    Click "Windons Machine" in the top tab to run the app
